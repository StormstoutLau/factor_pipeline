## Phase 3 — H1 真实缺陷与修复（P2 级，唯一）

**机理**：`np.full(n, c)` 型常数序列，`arr.mean()` 因浮点求和/除法舍入与元素值相差 ~1e-19，
使 `std(ddof=1) ≈ 1e-19 > 0`，绕过「std <= 0 拒绝」守卫，逐期 Sharpe = mean/std ≈ 1e17，
年化后 ≈ 5e17 垃圾值进入证据链。理论口径上常数序列方差为 0，必须显式拒绝。

**修复口径**：`np.ptp(arr) == 0.0`（max−min 精确为 0）显式拦截，语义与既有「零方差拒绝」一致。
共 5 处，覆盖全部 Sharpe / 长期方差 / 秩计算入口：

| 文件 | 位置 |
|------|------|
| `backtest/overfitting.py` | `_require_positive_std`（sharpe_ratio / DSR 共用入口）；`probability_of_backtest_overfitting` block 方差检查（拦截 PBO 块内常数列） |
| `backtest/effect_size.py` | `_sharpe_per_period`；`newey_west_se` |
| `backtest/specification_logger/spec_curve.py` | `joint_inference` 入口列检查（std 与 ptp 合并判断） |

**回归测试**（3 例，断言先复现浮点假阳前提 `std > 0` 再断言拒绝）：

- `test_t26b_constant_fp_slip_raises`（`test_overfitting.py`）：`sharpe_ratio(np.full(58, 0.01))` +
  PBO 矩阵块内常数列 → `ValueError`
- `test_t33b_constant_fp_slip_raises`（`test_effect_size.py`）：`newey_west_se(np.full(20, 0.01))` +
  `sharpe_ci(np.full(58, 0.02))` → `ValueError`
- `test_t40c_constant_column_fp_slip_raises`（`test_spec_curve_v2.py`）：`joint_inference` 含
  `np.full` 常数列 → `ValueError`

零新增依赖；`backtest/__init__.py` 零改动（P8-8k 复核）。

## Phase 5 — 结论与分级

| 级别 | 数量 | 明细 |
|------|------|------|
| P1（错误结论/数据风险，须回滚） | 0 | — |
| P2（应修） | 1（已修复） | H1 常数序列浮点假阳绕过零方差守卫 → 5 处 `np.ptp==0` 守卫 + 3 例回归测试，修复后探针 P6-6a/6b PASS |
| P3（披露） | 2 | ① stationary bootstrap 中间块长（≈8 vs 20，T=58）的 CI 宽度差不具统计功效，证据链使用时只应引用极端块长对照或延续率读数（P5-5e/5f）；② DSR 偏度/峰度惩罚方向依赖 (sr−sr0) 符号——sr<sr0 时惩罚方向反转属公式固有性质（Bailey & López de Prado 原文一致），解读负 z 的 DSR 时须注意 |
| 探针勘误 | 8 项 | 全部留档定性（见 Phase 2），不影响实现正确性 |

**总判定：PASS_WITH_FIXES** —— 唯一 P2 真实缺陷（H1）已修复并回归闭环；实现层未发现计量、
复现性、数据质量、稳健性或结论效度方面的其他缺陷；默认路径与既有口径零变更（golden 6 passed、
缓存代际 `v2.3.0-cache` 不变、pyproject diff 仅 version 一行）。
