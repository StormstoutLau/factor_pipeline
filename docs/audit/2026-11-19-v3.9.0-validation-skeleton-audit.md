## Phase 3 — H1/H2/H3 修复与回归测试（P2 级 3 项）

### H1 `backtest/trace.py` — content_hash ±inf 折叠

**根因**：`np.nan_to_num(data, nan=0.0, posinf=0.0, neginf=0.0)` 将 ±inf 折叠为 0.0；
IEEE 754 bytes 对 ±inf 自区分，折叠只会制造假冲突（漏检追溯分歧），无任何收益。

**修复**（`backtest/trace.py` L57-63）：

```python
if arr.dtype.kind in "fc":
    data = np.ascontiguousarray(arr, dtype=np.float64)
    mask = np.isnan(data)
    # ±inf 保留原值（IEEE bytes 唯一），仅 NaN 折 0.0 并以 mask 区分；
    # 折叠 inf 会使 [inf]/[0.0]、[+inf]/[-inf] hash 冲突（审计 H1）。
    digest.update(np.nan_to_num(data, nan=0.0).tobytes())
    digest.update(b"|nan|" + mask.tobytes())
```

**回归 T390-39**（`tests/test_trace.py::test_t390_39_content_hash_inf_distinct`）：
`[inf]`/`[-inf]`/`[0.0]` 三方 hash 互异；`[1.0, nan]` vs `[1.0, 0.0]` 互异（NaN 仍折 0.0 但以掩码区分）。

### H2 `tests/synthetic/panel.py` — 网格校验次序

**根因链**：静态读码发现步 3 bad 网格校验在步 6 adj_jump 缩放循环之后 → 缩放（`*= 0.5`）
破坏普通日 0.02 网格 → 校验必 raise（实跑证实 `ValueError: ... at (41, 0) (close=0.135)`）；
`grep` 全测试库无 adj_jump 引用 → 该场景从未被任何测试覆盖（测试盲区复合缺陷）。
修复方向依据 EXECUTION §2.2 步 3 语义（「普通日」= 主循环产出，校验对象是缩放前的生成结果）。

**修复**（`tests/synthetic/panel.py` L213-231）：主循环后先执行 bad 校验，再执行 adj_jump 缩放。

**回归 T390-40**（`tests/test_synthetic_panel.py::test_t390_40_adj_jump_buildable`）：

### H3 `scripts/verify_all.py` — collect 顶层非 dict 容错

**根因**：`json.loads` 后假定顶层为 dict；str/list 顶层是合法 JSON（collect 的容错口径
「非法/缺 tool 的文件跳过」应包含它们），直接 `payload.get` 崩溃。

**修复**（`scripts/verify_all.py` L24-32）：

```python
if not isinstance(payload, dict):
    # 顶层为标量/数组/字符串的合法 JSON 同属结构非法（审计 H3）
    continue
tool = payload.get("tool")
```

**回归 T390-41**（`tests/test_verify_all.py::test_t390_41_collect_skips_non_dict`）：
顶层 str/list JSON 直写后 collect 跳过，合法报告照常聚合（`set(reports)=={"verify_capacity_impact"}`）。
