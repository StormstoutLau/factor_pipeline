## Phase 4 — 语义（意图层）

| 设计意图 | 实现语义 | 判定 |
|---------|---------|------|
| qfq 禁止 = 防前复权改写历史击穿可复现 | 在记录入口（validator）拒绝，而非仅在文档声明；research 显式允许 | 一致 |
| 口径必须影响身份 = 同一实验不同口径不可混淆 | `price_convention`/`tradable_convention` 进 `ID_FIELDS` | 一致（DR-25） |
| 台账 = 防 p-hacking | family 预注册早于 trial；三分母区分 exploratory/backfill；`result_id` 不因 exploratory 改变 | 一致 |
| golden = 锁定「改了参数/代码」而非环境噪声 | 同环境 1e-10；跨环境 `env_match=False` + 报告 `PASS_WITH_ENV_DIFF`；NaN 率守卫 | 一致 |
| 契约门禁 = 研究入口可回退的护栏 | 默认关闭；FAIL exit 2；报告落盘但不阻断默认路径 | 一致 |
| hook = 可选旁路观测 | 默认 None；异常向上抛出（不吞） | 一致 |
| 代理口径 = 披露而非伪装 | 默认值写入 record 且枚举受限；`<field>_missing` 仅用于真正缺字段 | 一致 |
| 潜在语义风险 | `price_convention` 默认 `hfq` 会静默填补未声明的口径；`delist_coverage_unverified` 仅为词表示例、未产出 | P3 披露 |

**语义结论**：未发现「字面合规但意图错位」的实现；2 项风险降级披露（P3-3/P3-4）。
