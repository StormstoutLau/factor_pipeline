## §2 数据分级机制（建议）

### 2.1 分级维度

| 维度 | 字段 | 作用 | 缺失后果 |
|---|---|---|---|
| 价格 | `open/high/low/close` | 限价判定与成交判定 | 不可启用 |
| 量 | `volume` | 停牌/无成交推断 | 停牌不可判 |
| 除权 | `adj` | 除权参考价 → 正确限价 | 除权日限价错（§4） |
| 状态 | `name` | ST 判定（5%/10%/20% 分档） | ST 限价过宽 |
| 状态 | `suspend` | 停牌不可交易 | 高估可交易 |
| 状态 | `list_date` | IPO 前 5 日无限制 | 高估封锁（保守） |
| 状态（可选） | `is_delisting` | 退市整理期 10% | 退市期限价错 |

### 2.2 分级表

| 级别 | 定义（机械判据） | 处置 | 披露字段 | 偏差方向 |
|---|---|---|---|---|
| **D0 完整** | 上述 7 项齐备且覆盖 ≥ 阈值（建议 adj/name ≥ 99%，待标定） | 正常路径；`price_basis="raw_adj_ref"` | `data_tier="D0"` | 无系统偏差 |
| **D1 缺除权** | `adj` 缺失或覆盖 < 99% | `ref` 回退 `prev_close`；逐格 NaN 记 `limit_unknown` | `data_tier="D1"`、`price_basis="raw_close"`、`exdiv_unadjusted_days` | **乐观**（漏判涨停 ~56%） |
| **D2 缺 ST** | `name` 缺失或覆盖 < 99% | `is_st` 取最近已知状态前向填充；全缺则 `False` | `data_tier="D2"`、`st_assumed_cells` | **乐观**（限价过宽） |
| **D3 缺停牌** | `suspend` 缺失/列集不可对齐 | 用 `volume==0 & high==low` 推断；不可推断时全 `False` | `data_tier="D3"`、`suspend_unmodeled`、`inferred_suspended_cells` | **乐观**（高估可交易） |
| **D4 缺上市日** | `list_date` 缺失 | `no_limit` 全 `False` | `data_tier="D4"`、`ipo_unmodeled` | **保守**（高估封锁） |
| **D5 仅 close** | 无 high/low | **不启用**；报告省略 tradability 块 | `data_tier="unavailable"` | 不可用 |

> 组合缺失取**最差级**并累计 `missing_fields`；`D1+D2+D3` 同时出现时，报告必须写 `bias_direction="optimistic"` 且禁止进入收益结论。

### 2.3 分级判定（伪代码，可机械核验）

```python
def resolve_tier(coverage):          # coverage: {field: 0..1}
    if coverage.get("high") is None or coverage["high"] < 0.99:
        return "D5", ["ohlc"]
    if coverage.get("adj", 0.0) < 0.99:
        return "D1", ["adj"]
    if coverage.get("name", 0.0) < 0.99:
        return "D2", ["name"]
    if coverage.get("suspend", 0.0) < 0.99:
        return "D3", ["suspend"]
    if coverage.get("list_date", 0.0) < 0.99:
        return "D4", ["list_date"]
    return "D0", []
```

### 2.4 降级纪律（三条硬规则）

1. **不得向上兼容**：缺 `adj` 时禁止输出 `price_basis="raw_adj_ref"`；缺 `name` 时禁止输出 `st_source="name"`。
2. **每级必须可观测**：`report` 与 `meta` 必须同时含 `data_tier` 与 `missing_fields`；无该字段视为契约破损。
3. **每级必须有测试**：D1~D5 各至少 1 例（构造缺字段面板），断言分级、披露字段与偏差方向。

## §3 缺失数据下的社区实践

### 3.1 无 ST 表

| 做法 | 代表 | 精度/代价 | 适用 |
|---|---|---|---|
| 名称字符串规则（`ST`/`*ST`/`S*ST`/`SST`） | Qlib `NameDFilter` 生态、多数自建栈 | 中；零成本；更名日有滞后 | **本仓现用**（名称面板 2.97% ST 格） |
| 数据商字段 | RiceQuant `is_st_stock(order_book_id, count=1)`（含 ST/*ST）；JoinQuant `get_extras('is_st')` | 高；平台绑定 | D2 补强首选 |
| 名称变更历史 | Tushare `namechange`（起止日 + 变更原因，含「撤销ST」「从ST变为*ST」） | 高；需拉取一次即可构造逐日面板 | **离线补强的首选** |
| 数据内反推（观测 5% 限幅） | 社区零散做法 | 只能事后识别，且与低价股规则冲突 | 仅作交叉校验 |
| 指数/板块成分过滤 | Qlib filter pipeline | 只做剔除，不构造逐日状态 | 不做 §3.1 的主路径 |

**判断**：本仓名称规则 + `namechange` 交叉验证，可把 ST 状态从「推断」升级为「有据」；无需引入平台依赖。

### 3.2 无退市标志

| 做法 | 证据 | 处置建议 |
|---|---|---|
| 名称含「退市」前缀 | 上交所/深交所退市整理期公告均冠「退市」标识（如「退市创兴」「退市太和」） | 可作 `is_delisting` 的**首日识别**信号；需与「首日无涨跌幅、其后 10%」配合 |
| 生命周期表（上市日 + 最后交易日） | 新浪财经：退市数据不可一删了之，应保留上市/停牌/复牌/终止上市全生命周期 | 用「最后有效报价日」后停止交易，避免幸存者偏差 |
| 交易所风险警示板列表 | 上交所「风险警示板」页分「风险警示股票 / 退市整理股票」 | 可按日快照补历史，但成本高 |
| 规则口径 | 退市整理期：首日无涨跌幅，此后 **10%**（沪深主板） | 本仓 `no_limit` 需覆盖「退市整理首日」，当前仅覆盖 IPO |

**判断**：D0 之前，`is_delisting` 可保持可选；但「退市整理首日无限制」应作为 `no_limit` 的第二来源（与 IPO 并列），否则退市股首日会被误判为涨停/跌停。

### 3.3 无限价表

| 做法 | 代表 | 误差（本机实测，主板） | 建议 |
|---|---|---|---|
| 公式自算（前收/除权参考价 × 比例，half-up 取整） | 本仓 `compute_limits`；交易所规则公式 | 基准（精确判定 101,890 涨停格） | **主路径** |
| 固定收益率阈值 0.095 | Qlib 配置示例；社区代码 `limit_pct = 0.095` | 误判 **26,029**、漏判 212 | 仅作粗筛 |
| 固定收益率阈值 0.099 | 部分社区代码 | 误判 12,362、漏判 2,279 | 优于 0.095，仍不可替代 |
| 收益率阈值 0.10 | 直观写法（`return >= 0.1`） | 误判 9,622、**漏判 38,449** | 明确不可用（社区文章已警告） |
| `high==low` 三态 | 腾讯云/华为云社区 | 只判「全天一字」，不判板块/ST | 作为**不可成交**的加严条件 |
| 数据商限价表 | Tushare `stk_limit`（2007-01-04 起，含 SSE/SZSE/BSE） | 权威 | **对拍与校准源**（离线快照） |

> 社区「0.095」的成因：留 0.5% 余量以吸收取整与停牌噪声；代价是**大量误判**（+25.6%）。本仓精确价 + eps 容差没有该问题，但依赖 `adj` 与 ST 状态正确。

### 3.4 组合降级矩阵

| 缺失 | 可做 | 不可做 | 必须披露 |
|---|---|---|---|
| adj | 原始价限价（除权日偏差） | 除权日成交判定 | `exdiv_unadjusted_days` |
| name | 统一按 10%/20%/30% 分板块 | ST 精确限价 | `st_assumed_cells` |
| suspend | 量价推断停牌 | 精确停牌日 | `suspend_unmodeled` |
| list_date | 无 IPO 豁免 | 新股前 5 日判定 | `ipo_unmodeled` |
| 全部状态 | 仅「价格触及限价」证据 | 可成交性结论 | `evidence_level="price_only"` |

## §4 专题：除权参考价对齐

### 4.1 规则依据（E2）

- 沪深北交易所交易规则 **4.3.2**：除权（息）参考价 = [(前收盘价 − 现金红利) + 配股价 × 流通股份变动比例] / (1 + 流通股份变动比例)。
- 涨跌幅价格 = **前收盘价 × (1 ± 比例)**，结果**四舍五入至 0.01 元**；「如期间内证券发生过除权除息，则对收盘价格做相应调整」。
- 创业板/科创板 ST 仍 20%、北交所 30%；沪深主板 ST 自 **2026-07-06** 起由 5% 放宽至 10%（本仓规则表已含该分段）。

### 4.2 为什么社区常「看不到」这个问题

1. **平台代劳**：JoinQuant/RiceQuant 直接提供 `limit_up/limit_down`，用户无需自算，问题被数据层吸收。
2. **阈值法绕过**：9.5%/9.9% 收益率阈值不涉及价格取整，天然不问「前收是哪一天、是否除权」——代价是 §3.3 的误判。
3. **全流程用复权价**：前复权序列抹平了除权跳空，限价看起来「总是对的」，但价格水平已非真实价，无法与交易所限价对齐。
4. **样本占比低**：除权日仅占全样本 0.489%，回测聚合指标几乎看不出异常 → 缺乏发现动机。
5. **少量正确实践未成主流**：有博客明确「指标/信号用后复权，成交/手数/涨跌停用不复权真实价」（E3），与本仓 `raw + ref` 一致，但属少数派。

### 4.3 本机实测误差（E1）

样本：2020-01-02 ~ 2026-01-30，`close/high/low/adj` 三方交集（1394 日 × 5688 只）。

| 指标 | 主板（10%） | 创业板/科创板（20%） |
|---|---|---|
| 除权股票×日 | 24,538 | 12,823 |
| 限价与正确值不同 | 62.3% | 71.8% |
| 真实涨停格 | 369 | 56 |
| **漏判**（用原始昨收算） | **206（55.8%）** | **29（51.8%）** |
| 误判 | 26 | 6 |
| 真实跌停格 | 142 | 7 |
| **漏判** | **70（49.3%）** | 2 |
| 误判 | 22 | 5 |

**示例**：`002315` 2020-03-10，除权比例 0.7468，昨收 27.20 → 正确涨停价 22.34；用未除权昨收得 29.92（差 7.58 元 = 34%）。

> 口径限制：探针按板块固定比例，未套用 ST 5%（2026-07 前）与「前收 ≤0.1 元时涨跌幅 0.01 元」细则，故读数为**量级估计**，不是逐格审计值。

### 4.4 偏差方向与经济含义

- 漏判涨停 ≫ 误判 → 「以为买得到」→ **高估可执行性**，与「回测虚高」方向一致。
- 除权日多集中在分红季（5-7 月），若策略恰在分红季调仓，偏差会集中放大。
- 跌停漏判 → 「以为卖得掉」→ 高估止损可执行性。

### 4.5 三种实现口径对比

| 口径 | 限价正确性 | 收益正确性 | 复杂度 | 结论 |
|---|---|---|---|---|
| 全复权价（前/后复权） | ✗ 价格水平失真 | ✓ 收益连续 | 低 | 不可用于限价 |
| 原始价 + 未对齐昨收 | ✗ 除权日错（§4.3） | ✓ | 低 | **社区主流，不可取** |
| 原始价 + 除权参考价（本仓） | ✓ | ✓ | 中（需 `adj` 与取整） | **推荐** |

### 4.6 残余误差与待验证

| # | 问题 | 现状 | 建议 |
|---|---|---|---|
| E-1 | `adj` 缺 81 日 → `limit_unknown` | 已实测缺口 | 前后向填充 + `exdiv_unadjusted_days` 披露 |

## §5 对分级机制与后续批次的建议

1. **先做对拍再接线**（提纲 §9 方案 C）：用 1 个月全市场 + 分红季 1 个月，与 `stk_limit` 逐格对拍；一致率 ≥ 99.9% 才进入 D0。
2. **D1/D2/D3 仅用于「敏感性分析」**，不得进入结论性收益；报告中必须双列（D0 主口径 + 降级口径）。
3. **`stk_limit` 作为离线审计源**而非运行时依赖：只存「对拍报告 + 差异清单」，避免新依赖。
4. **`namechange` 用于 ST 升级**：一次性构造逐日 ST 面板，替换名称字符串推断；保留名称规则作为回退。
5. **规则表补两处**：退市整理首日无限制、低价股 0.01 元细则（E-4/E-5）。
