针对两个问题——(1) 框架数据层统一治理/统一契约/接入格式规范对齐；(2) A 股幸存者偏差、前视偏差、复权、ST/停牌处理——原提案给出三层拆分：

> **原文全文见[附录 A](#附录-a-原始提案全文as-proposed)**；本节仅为结构摘要。

## §3 第二轮：H1/H3 实证深化

> 方法：只读探针（临时 inline Python，用后不留脚本），直接读 `E:\Ashare_data\market_data`。
> 关键数字均为一手实测，非转述。

### 3.1 H1 深化：数据层比设计假设更丰富

**目录盘点（`market_data`）**：

| 文件 | 体量 | shape / 语义 | 结论 |
|------|------|-------------|------|
| `all_dates.pkl` | ~0 MB | **list，1475 个交易日**，2020-01-02→2026-01-30，跳过周末 | **交易日历已存在**（B8 日历缺口部分有现成数据） |
| `stock_name.pkl` | 102 MB | 1474×6053，object+float64 混合，index 止 2026-01-29 | **历史名称面板**（非静态映射） |
| `stock_suspend.pkl` | 8.5 MB | 1475×5681，object，取值 'S'/'R' | **停牌事件表**（非每日 0/1 状态） |
| `stock_volume/open/high/low/return.pkl` | 各 67 MB | 1475×5688 | 全部存在，`load_market` 未加载 |
| `stock_adj.pkl` | 63.5 MB | 1394×5691 | 见 §3.2 |
| `list_date_df.pkl` | 0.1 MB | DataFrame (5797,1)，index=代码，列=list_date（回溯至 1990/1991） | 覆盖 5797 只，**多于价格面板 5688**（提示含面板外个股，退市覆盖完整性待核验） |
| `index_dict.pkl` | 214 MB | 未核验（疑似指数成分） | 列为未决项 §6 |
| `stock_df.pkl` | 67 MB | 未核验 | 列为未决项 §6 |

**关键语义实测**：

1. **`stock_return` 是复权收益**（非原始收益）：
   - `corr(stock_return, adj close daily) = 0.99998`
   - `corr(stock_return, raw close daily) = 0.99516`
   - 中位数 = 0.0（大量停牌日收益为 0）
   - → 与设计 §5.2 `return = close*adj 下期收益` 口径一致。

2. **`stock_suspend` 是事件表**：取值 'S'（停牌，18242 次）/ 'R'（复牌，2700 次），末行 16 个非空事件。
   - → 需重建逐日停牌状态（如 `cumsum(S) > cumsum(R)` 判停牌中），**不是简单 load 即用**；'S'/'R' 完整语义待核验。

3. **`stock_name` 可推导历史 ST**：
   - 2606 / 6053 列名称随时间变化；459 列曾含 "ST"。
   - 样例 `000004: ST国华 → 国华网安 → *ST国华`。
   - → **历史 ST 状态可从现有数据推导**，不是数据缺口；但属**名称代理口径**（非官方 ST 标记），须披露。

4. **`all_dates` 是交易日历**：1475 个交易日，与 close 行数一致，首尾 2020-01-02 / 2026-01-30，跳过周末。
   - → 仅覆盖面板窗口（2020 起），非全历史；list of str 需转 DatetimeIndex。

**H1 深化结论**：停牌 / ST / 退市 / 日历 / 量价数据**已存在**，上一轮把它们归为"等外部采购的专项 B"是错误归类。它们是**专项 A 的接入/规范化/推导任务，可立即做**。

### 3.2 H3 深化：adj 为 hfq，"非单调"主要是微小数值噪声

**hfq 判定证据**（5684 列）：

| 指标 | 数值 | 解读 |
|------|------|------|
| `last_valid == 1` 占比 | **2.2%** | 排除 qfq（qfq 应几乎全部末值=1） |
| `first_valid == 1` 占比 | 33.8% | 2020 后 IPO 无前期分红，首值=1（累计自上市日的 hfq 特征） |
| first_valid 中位 → last_valid 中位 | 1.7069 → 2.4682 | 因子随时间增长 |
| 严格非降列 | 1085 / 5684 (19%) | 见下方幅值分解 |

→ **`stock_adj` 判定为后复权（hfq）累计因子，高置信**。"禁 qfq"是防回归契约锁定，当前已满足。

**行数不对齐（新发现的数据质量问题）**：

```
adj rows   = 1394
close rows = 1475
close 有 81 个交易日不在 adj 中（如 2020-01-10 / 2020-02-03 / 2020-02-19 ...）
adj 无额外日期
```

→ adj 与 close **行数不对齐**，疑似数据导出/节假日处理差异，需专项 A 核验修复。`load_market` 用 `adj.reindex(index=close.index)` 会把这 81 日填 NaN。

**"非单调"幅值分解**（逐列 `np.diff(adj)` 负值，NaN 压缩后）：

| 类别 | 列数 | 相对幅度 | 解读 |
|------|------|---------|------|
| 严格非降（无回落） | 1085 | — | 正常 hfq |
| 仅小回落 | **4578** | 1e-6 ~ 0.1% | **微小数值噪声**（除权除息计算精度） |
| 显著回落 | **21** | > 0.1% | 可能真实因子回落（配股/特殊除权），需个案核验 |

- 最大单次绝对回落 5.75（600069），相对幅度约 6.5%。
- 校验：1085 + 4578 + 21 = 5684 ✓。

→ 81% 列的"非单调"是 **<0.1% 的微小数值噪声**，不是真实因子回落；仅 21 列（0.37%）显著回落需个案分析。**H3 风险降级**。

**探针 bug 披露（不影响结论）**：幅值分解探针在打印"显著回落样例"时，`from/to` 用了 `rel` 的索引而非映射回 `cv` 的索引，导致样例显示 `from==to` 但 `rel_drop>0` 的矛盾。**判断逻辑 `np.any(rel>1e-3)` 不依赖该索引，"仅 21 列显著回落"的结论仍成立**；样例数值不可引用，需修复索引映射后重取。

### 3.3 探针可复现性要点

- 数据根：`E:\Ashare_data\market_data`；只读，未写任何数据。
- hfq 判定：逐列取首/末有效值，统计 `==1` 占比与单调性。
- 幅值分解：逐列 `np.diff`，负值按相对幅度 `−Δ/prev` 分桶（1e-6 / 1e-3 阈值）。
- return 口径：`stock_return` 与 `close.pct_change()`、`(close*adj).pct_change()` 分别求 Pearson 相关（前 200 列样本）。
- 探针为临时 inline 脚本，用后不留存；关键数字已固化于本记录 §3.1/§3.2。
