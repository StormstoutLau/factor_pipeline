## §2 market_value 缺口

### 2.1 形态

- 5467 只个股**全市场同日**最后有效 (2026-01-23), 其余 217 只散落更早日期 (退市/长期停牌)
  → 是**面板整体截断**, 不是个股数据错误;
- 面板 shape (1470, 5684) 比行情 (1475, 5688) 少 5 行 4 列 (1-26~1-30 上市新股);
- 末 15 个交易日非空数 5452-5467, 逐日正常 → 断点在 1-23 之后, 非渐进缺失。

### 2.2 根因

mtime **2026-01-27 11:13** 早于行情文件 3 天, 且此后再未刷新
→ mv 走**独立导出流程**, 01-27 生成时源数据只到 01-23, 之后管道未再产出。
与行情刷新 (每日 16:20 后) 不同步, 属数据管道调度缺口, 非本项目计算问题。

### 2.3 量级 (缺口 2026-01-23 → 2026-01-30)

| 指标 | 数值 |
|------|------|
| 复权价比值 (中位 / p5 / p95) | 0.9655 / 0.8817 / 1.0821 |
| turnover 分母 stale 偏差 (中位 / p5 / p95) | **+3.57%** / -7.58% / **+13.42%** |
| 末月 `turnover_1m` 与近似真实值秩相关 | **0.9966** |
| 与「完全截至 1-23」版本秩相关 | 0.9928 |
| 末月四因子齐备数 (对比 2025-12) | 5429 (5425) — **无因子缺失** |

→ 分母 stale 只造成**横截面排序的微扰** (秩相关 0.997), 不造成缺失。

### 2.4 影响面

- **容量压力测试**: `build_panels` 构造的 `mv_m` **未进入主流程**
  (代码中仅 3 次出现, 均在构造/返回), 且末月被 `ok` 掩码剔除 → **零影响**;
- **多头端落地研究**: mv 用于 `turnover_1m`、`size_neutral`、`exSmall30`、市值加权、
  `mv_rank`/`mv_pct` 诊断 — 末月 stale, 但末月权重为 0 (`ret.shift(-1)` 缺失)
  且不进入绩效/超额/换手统计 → **绩效零影响**, 仅末月展示行 stale;
- **末月 turnover 日频**: 2026-01-26 ~ 01-30 共 5 天非空 = 0, 21 日均值靠 `min_periods=15` 存活。

## §6 复现

诊断口径:

1. 逐文件读取, 索引转 datetime, 统计逐行非空列数 (数值面板要求非空且非 0, 文本面板仅非空);
2. 「最后满覆盖日」= 非空列数 ≥ 峰值 × 95% 的最后一个交易日;
3. mv 个股最后有效日 = `DataFrame.apply(last_valid_index)` 的分布;
4. stale 偏差 = 复权价 (`close × adj`) 在缺口区间的比值取倒数 − 1;
5. barra/行业以文件 mtime + 最后截面日期判断停更批次。

脚本为临时探针 (`out/probe_data_gaps.py` / `out/probe_mv_stale.py`), 结果留档
`out/data_gaps_report.txt`, 脚本已删除。
