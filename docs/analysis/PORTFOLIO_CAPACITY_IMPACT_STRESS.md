三条核心结论:

1. **Q5 的多头超额不够支付冲击成本**: 1 亿时全成本净超额已降到 +0.69% (t 0.25),
   5 亿归零, 10 亿为 -0.70%。它不是「小容量 alpha」, 而是**低风险画像的风险补偿**,
   不宜作为独立多头产品。
2. **exQ1 的容量由低流动性层决定**: 总量 p95≤10% 容量 203 亿, 但低流动性 30% 层

   现实容量应表述为 **约 90-100 亿 (保守) / 200 亿 (10% p95 上限)**,
   盈亏平衡在 295 亿 (c=1.0) 至 1181 亿 (c=0.5) 之间。
3. **alpha 集中在 S1, S2 在容量约束下不显著**: S1 @100 亿仍 +4.01% (t 3.52);
   S2 @100 亿 +1.01% (t **1.11**), 可交易版 +0.63% (t **0.65**)。
   多头端报告的 S2 边际显著 (p=0.050) **不能**在 100 亿容量下延续。

## §2 数据与口径

### 2.1 数据与单位

| 项 | 口径 |
|----|------|
| 样本 | 2020-01-31 → 2026-01-31, 73 个月末; 基准有效 72 个月 |
| 因子 | 4 因子复合 (turnover_1m / reversal_1w / volatility_1m / max_ret_1m), 与上游报告逐位一致 |
| 组合 | 月末形成, 月频调仓, 等权; Q5 = 前 20%, exQ1 = 剔除最差 20% |
| 可交易版 | 剔除形成日 ST/退 / 停牌 / 涨停 |
| `stock_amount` | **千元** (以 600519/000001/300750/688981 校验; 全市场日成交额 ~2.9 万亿元) |
| `market_value` | **万元** (600519 市值 1.67e12 元校验通过) |
| 基准 | 同一可投资域等权收益 (不做冲击成本扣减) |
| 基础费率 | 10bp / 单边, 成本 = 2 × 单边换手 × 费率 |

### 2.2 冲击成本模型

单票单边交易额:

```
notional_i,t = AUM × |Δw_i,t|
participation_i,t = notional_i,t / ADV_i,t
ADV_i,t = 形成日当日及之前共 21 个交易日的平均成交额 (元)
```

平方根模型 (Almgren 型, 中央口径 **c = 0.5**):

```
impact_i,t = c × σ_i,t × sqrt(min(participation_i,t, 1))
```

- `σ_i,t` = 形成日当日及之前共 21 个交易日的日收益率标准差, clip 到 [0.5%, 20%]
  (复审 P8: 样本内 clip 边界未绑定, 与无 clip 结果差 0.00pp);
- 敏感性: c = 0.1 (乐观) / 0.5 (中央) / 1.0 (保守)。

线性模型 (对照):

```
impact_i,t = k × min(participation_i,t, 1),  k = 2.5bp / 1% ADV (中央)
```

组合月度冲击成本 = `Σ_i |Δw_i,t| × impact_i,t`; 年化 = 月度均值 × 12。

> 数据处置 (复审 P3/P8 量化): 缺失 ADV 的票-月 (占交易 cells 0.01%, 冲击贡献 ≤0.09%)
> 按 100% ADV 参与率计冲击 (保守) 且不计入参与率分位数; σ 缺失 (21 日历史不足的次新股)
> 以当月截面中位数填充。两者对结论无实质影响。

### 2.3 容量与盈亏平衡定义

- **容量 (p95 / p99)**: 所有「有交易的票-月」参与率分布的 95/99 分位;
  给定上限 `cap`, 由 `participation ∝ AUM` 解析反推 `AUM = cap / (p95/AUM_ref)`;
- **盈亏平衡 AUM**: 全成本净超额 = 0 的 AUM;
  平方根模型 ∝ sqrt(AUM), 线性模型 ∝ AUM;
- 参与率 > 100% 记为 breach, 单独报告占比。

> 容量口径是**统计约束**, 不是硬性成交上限; 真实交易可通过拆单/多日执行降低参与率,
> 但会引入延迟成本与 alpha 衰减 (见 §8)。

> 解析盈亏平衡的封顶锚点偏差 (复审 P5): 解析外推假设 `冲击 ∝ sqrt(AUM)` 全程成立,
> 但 100 亿锚点处参与率封顶已在绑定 — exQ1 轻微 (p99 13.5%) → 解析 BE 为**下界**
> (含封顶的数值复解 1351 亿 vs 解析 1181 亿; c=1.0: 301 vs 295 亿);
> Q5 深度封顶 (p99 248%) → 解析 BE **偏大** (数值 ~4 亿 vs 解析 4.8 亿)。
> 容量口径不受影响: 参与率分位数对 AUM 严格线性 (P4 逐位验证),
> 解析容量与网格插值精确一致 (P5)。

|------|----|-----------|-----------|-----------|---------|
| exQ1_EW | 低 | 15.1% | 0.07% | **10.16%** | **98 亿** |
| exQ1_EW | 中 | 45.2% | 0.03% | 4.66% | 215 亿 |
| exQ1_EW | 高 | 39.6% | 0.01% | 1.57% | 639 亿 |
| exQ1_EW_tradable | 低 | 15.6% | 0.11% | **11.19%** | **89 亿** |
| exQ1_EW_tradable | 中 | 45.4% | 0.05% | 4.98% | 201 亿 |
| exQ1_EW_tradable | 高 | 39.1% | 0.02% | 1.64% | 608 亿 |
| Q5_EW | 低 | 45.4% | 30.75% | **142.04%** | **7 亿** |
| Q5_EW | 中 | 36.5% | 9.99% | 26.98% | 37 亿 |
| Q5_EW | 高 | 18.1% | 2.22% | 7.19% | 139 亿 |

- exQ1 的低流动性层只占交易额 15%, 但其 p95 参与率在 100 亿已达 10% —
  **容量由这 15% 的尾部决定**, 而不是总量;
- Q5 的低流动性层占交易额 45%, p50 参与率就达 30.75%, p95 142% —

> 口径注 (复审 P3/P7): 分层 rank 基于全可投资域 (含 ST/停牌/涨停票) 的成交额分位,
> 可交易变体同一口径; 若改用可交易域 rank, exQ1 可交易低层 10% 容量 89 → 94 亿 (+5%),

> 计入参与率分位池与换手均值: 分位影响 <0.5pp (容量 203 → 204 亿, 保守方向),
> 换手 exQ1 1.78 → 1.72×/年 (剔除后); 冲击成本 / 净超额 / 分段统计已将其剔除, 不受影响。

## §7 结论与落地建议

### 7.1 对外可用的容量表述

| 口径 | exQ1 (可交易) | 说明 |
|------|--------------|------|
| 保守容量 | **约 90-100 亿** | 低流动性层 p95 参与率 ~10-11%, 月末执行 |
| 建议上限 | **200 亿** | 总量 p95 10%, 需低流动性层拆单/多日执行 |
| 盈亏平衡 (c=0.5) | 800 亿 | 乐观冲击系数, 不建议对外承诺 |
| 盈亏平衡 (c=1.0) | 200 亿 | 保守冲击系数, 与建议上限一致 |

**不建议**使用 `p95 ≤ 20%` 的 368 亿口径 — 该口径下低流动性层参与率已 >20%,
冲击模型会失效。

### 7.2 实施建议

1. **形态**: 宽基底仓 + 排除最差 20%, 等权/接近等权; 不做个股集中;
2. **执行**: 低流动性层单票单日参与率上限 10%, 必要时拆 2-3 日;
   月末前后各 1 日分批, 降低月末集中度;
3. **容量监控**: 按 §5 的低/中/高流动性层分别监控 p95 参与率,
   不要只看组合总量;
4. **Q5 处理**: 不作为独立多头产品; 如需暴露「低风险画像」, 应以因子倾斜/权重调整
   表达, 而不是持有 Q5 组合;
5. **S2 验证**: 2026 年起持续跟踪 S2 的冲击后净超额; 在 t < 2 之前,
   对外材料应标注「S1 证据, S2 待验证」。

### 7.3 与上游结论的关系

上游多头端研究证明 exQ1 **有**净超额 (+3.08%, t 4.08), 但未回答可实施性。
本报告补上该缺口后, 结论收敛为:

> **exQ1 是一个容量约 100 亿、alpha 集中在 S1 的基准增强策略;
> Q5 是风险画像, 不是可扩容 alpha。**

## §8 限制

| 限制 | 影响 | 缓解 |
|------|------|------|
| 冲击模型为 stylized (平方根/线性), c 未用 A 股成交数据校准 | 容量是量级估计, 不是精确值 | 同时报告 c=0.1/0.5/1.0 与线性对照; 用 100-300 亿区间表述 |
| 月末单时点成交假设 | 高估月末集中冲击 | 建议拆 2-3 日; 未建模延迟成本 |
| 无价格冲击反馈 / alpha 衰减 | 高估容量 (冲击会削弱信号) | 保守取 c=1.0 的 200 亿上限 |
| 无跨股票/跨策略共同冲击 | 低估组合拥挤成本 | 低流动性层单独设限 |
| ADV 用过去 21 日, 未做成交量预测 | 流动性收缩期低估参与率 | 容量随流动性 regime 下移; 需压力测试 |
| 费率统一 10bp/单边, 未区分印花税/过户费 | 略低估卖出成本 | A 股卖出印花税 5bp 可另加; 影响 <0.1%/年 |
| 月频, 无日内执行 | 无法评估 VWAP/TWAP 执行质量 | 落地前需执行算法回测 |
| 样本 2020-2026, 含极端流动性收缩 (2024-02) | 容量对 regime 敏感 | 报告的是全样本均值; 极端月 p99 更高 |
| 容量定义基于 p95 参与率, 非硬约束 | 尾部仍可能无法成交 | 报告 p99 与 breach 率 (100 亿时 0.06%) |
| 样本末月为幻影清仓 (下月无收益, 权重置零): 计入换手均值与参与率分位池 | 换手 exQ1 虚增 ~0.06×/年 (1.78 → 1.72 剔除后); 分位影响 <0.5pp, 容量 203 → 204 亿 (保守) | 与上游口径一致 (V1 对账依赖); 冲击/净超额/分段已剔除该月; 复审 P3 量化 |
| 解析盈亏平衡为解析外推, 方向取决于 100 亿锚点封顶 | exQ1 解析 = 下界 (数值复解 1351 亿 vs 1181 亿); Q5 解析偏大 ~20% (数值 ~4 亿) | 数值复解见 §12 P5; Q5 不可产品化结论不依赖 BE 精值 |
